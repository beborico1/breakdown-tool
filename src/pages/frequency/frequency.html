AnkiConnect Setup Guide Learn how to connect Anki to sync your vocabulary
1
Install Anki

Download and install Anki (free, open-source flashcard app) if you don't have it already.

2
Install the AnkiConnect Add-on

In Anki, go to Tools → Add-ons → Get Add-ons... and enter this code:

2055492159

Click OK to install, then restart Anki.

3
Keep Anki Running

AnkiConnect works by running a local server on your computer. Anki must be open and running whenever you want to sync words from this extension.

Note: No extra configuration is needed. AnkiConnect works out of the box on localhost:8765.
4
Verify the Connection

Look at the status dot next to the "Sync to Anki" button above:

Green = Anki is running and connected
Red = Anki is not running or AnkiConnect is not installed
5
Sync Your Words

Select words using the checkboxes on each word card, then click Sync to Anki to choose a deck and send them to Anki as flashcards. You can use Select All / Deselect All to quickly manage selections.
